# โหรพัฒนา · Hora Patana

เว็บแอปเรียนโหราศาสตร์ไทย ตามตำราของบรมครูโหร **พัฒนา พัฒนศิริ**
สำหรับ Miracle Life Coach Co., Ltd. — เนื้อหาและภาพมาจาก [horapatana.com](https://horapatana.com)

ใช้ได้ทั้งมือถือ แท็บเล็ต และเดสก์ท็อป · ไม่มี build step ไม่มี dependency

---

## รันดู

```bash
python -m http.server 4173 --directory build
```

เปิด <http://localhost:4173>

หน้าแรกมี 3 แบบ เลือกด้วย query string:

| URL | หน้าแรก |
| --- | --- |
| `/?home=index` | สารบัญบทเรียน (ค่าตั้งต้น) |
| `/?home=chart` | โปสเตอร์ฤกษ์วันนี้ + พื้นดวงย่อ |
| `/?home=course` | ห้องเรียนของครู |

## โครงไฟล์

```
build/
  index.html          โครงหน้า โหลด app.css / data.js / app.js
  app.css             ดีไซน์ "ตำราใต้แสงเทียน" — ขาว / แดง / ทอง
  app.js              ตรรกะทั้งหมด vanilla JS ไม่มี framework
  data.js             เนื้อหาทั้งหมดอยู่ที่นี่ที่เดียว
  logo.png            ตราบรมครูโหร
  assets/
    site/             ภาพจาก horapatana.com (ดู README ในโฟลเดอร์)
    zodiac/           ภาพราศีสำหรับแถบ marquee
dist/
  horapatana.html     เวอร์ชันไฟล์เดียว ฝังทุกอย่างไว้ในไฟล์ เปิดได้เลย
```

## แก้เนื้อหา

ทุกอย่างอยู่ใน `build/data.js` — แก้ที่นี่ที่เดียว ไม่ต้องแตะ `app.js`

| ตัวแปร | ใช้ทำอะไร |
| --- | --- |
| `LESSONS` | บทเรียนทั้ง ๙ บท พร้อมเนื้อหาในแต่ละบท |
| `TEACHER` | ประวัติอาจารย์พัฒนา · รูป · ไทม์ไลน์ |
| `SUCCESSOR` | ประวัติ อ.ร่มฉัตร (ผู้สืบทอด) |
| `HONOURS` | รางวัลและการจัดอันดับจากสื่อ |
| `STATS` | แถบตัวเลขหน้าแรก |
| `COURSES` / `SERVICES` | คอร์สเรียน / บริการ |
| `TESTIMONIALS` | รีวิวลูกศิษย์ — **ว่างไว้** ใส่ของจริงแล้วส่วนนี้จะโผล่เอง |
| `ARTICLES` | บทความ — **ว่างไว้** เพราะเว็บจริงยังขึ้น "เร็วๆ นี้" |
| `CONTACT` | เบอร์โทร · ไลน์ไอดี |

### หลักที่ยึดไว้

ตัวเลขและคำรับรองในแอป **ใส่เฉพาะที่ยืนยันได้จากเว็บจริง** เท่านั้น
จำนวนลูกศิษย์ ผู้ติดตาม YouTube ราคาคอร์ส และรีวิว — เว็บไม่ได้ระบุไว้
จึงเว้นว่างแทนที่จะเดา เพราะติดตัวเลขผิดบนธุรกิจจริงเสียหายกว่าไม่ติด

## สร้างไฟล์เดียวจบ

`dist/horapatana.html` รวม CSS · JS · ข้อมูล · รูปทั้งหมดไว้ในไฟล์เดียว
ดับเบิลคลิกเปิดได้เลย เหลือโหลดจากภายนอกแค่ Google Fonts

## รายละเอียดที่ตั้งใจทำ

- **ฟอนต์หัวกลม** — Noto Sans Thai Looped + Sarabun + Charmonman ทั้งหมดมีหัว
- **อ่านง่ายสำหรับผู้สูงอายุ** — เนื้อความ 17px ตัวเล็กสุด 12px ระยะบรรทัดขั้นต่ำ 1.38
  (ภาษาไทยซ้อนสระบนกับวรรณยุกต์ ถ้าบรรทัดแน่นกว่านี้จะโดนตัด)
- **จตุโกณ** — ดวงชะตาแบบตารางไทย สลับเป็นวงกลมได้
- **สีดาวประจำวัน** — เลขดาว ๑–๙ ลงสีตามวันที่ครอง
- **เลือกวันเกิดจาก dropdown** — ปี พ.ศ. ๑๐๐ ปี · ๗๗ จังหวัด · จำนวนวันปรับตามเดือนและปีอธิกสุรทิน
- **ปุ่มไลน์** — อยู่ทุกหน้า (มือถือลอยมุมขวาล่าง เดสก์ท็อปอยู่ท้าย sidebar)
- เคารพ `prefers-reduced-motion` ทั้งแอป
